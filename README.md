# Switch Kit

An open-source library that makes web apps easier to use with one or two switches, large buttons, or head and eye pointers. It is built with people with cerebral palsy and other motor disabilities in mind, and aims for plain setup with no account or tracking.

## What is here

- `src/switch-scan.js`: a small scanning engine that steps focus through the controls on a page so one switch can select them.
- `examples/basic.html`: a page to try it in a browser.
- `docs/`: notes on how switch access works and what the library should support.

## Try it

Open `examples/basic.html` in a browser. Press the space bar to act as the switch.
